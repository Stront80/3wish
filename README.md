# «Три желания» — версия GitHub Pages с комментариями

В этой версии добавлены поясняющие комментарии в HTML, CSS и JavaScript. **Файл `CNAME` намеренно отсутствует**: GitHub Pages будет использовать стандартный адрес GitHub Pages, а не привязывать сайт к пользовательскому домену. В коде не настроен редирект на `3wishesit.site`.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub. Для публикации на корневом адресе аккаунта используйте имя вида `ВАШ_ЛОГИН.github.io`; иначе сайт обычно будет доступен по адресу `ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.
2. Загрузите файлы из этого архива в корень репозитория. В корне должны находиться `index.html`, `styles.css`, `app.js`, `privacy.html`, `favicon.svg` и `README.md`.
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Дождитесь завершения публикации и откройте адрес, который GitHub показывает в разделе Pages.

## Почему сайт не перенаправляет на `3wishesit.site`

- В архиве нет файла `CNAME`, который привязывает GitHub Pages к пользовательскому домену.
- В HTML нет meta refresh или JavaScript-команды, перенаправляющей на `3wishesit.site`.
- `window.location.href` в `app.js` используется только для ссылки `mailto:` — это открытие почтового приложения, а не переход на другой сайт.
- Если в репозитории GitHub в **Settings → Pages → Custom domain** ранее был указан `3wishesit.site`, удалите это значение и сохраните настройки. Также проверьте настройки DNS у регистратора: этот архив не может изменить внешние DNS-записи.

## Где что редактировать

- `index.html` — тексты, разделы, контакты, поля формы и SEO-метаданные.
- `styles.css` — цвета, размеры, сетки, оформление и адаптация для мобильных устройств.
- `app.js` — мобильное меню, проверка полей и подготовка письма-заявки.
- `privacy.html` — политика обработки персональных данных.
- `favicon.svg` — значок вкладки браузера.

## Важное ограничение формы

GitHub Pages — статический хостинг: он не запускает Node.js и не отправляет письма с сервера. Форма проверяет заполнение и открывает почтовое приложение с подготовленным письмом на `mailbox@familypost.ru`; посетителю нужно нажать «Отправить». Для автоматического получения заявок понадобится серверная версия или отдельный сервис обработки форм. Не размещайте SMTP-пароли в публичном репозитории.

## Перед публикацией

- В `privacy.html` остаются юридические поля, которые нужно заполнить реальными сведениями об операторе и порядке обработки данных. Проверьте документ до сбора заявок.
- Отправьте тестовую заявку с телефона и компьютера.
- При размещении в репозитории-проекте (не `ВАШ_ЛОГИН.github.io`) проверьте относительные пути к ресурсам, если решите менять структуру каталогов.
